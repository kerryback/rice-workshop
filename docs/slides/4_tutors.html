Gemini Notebook (previously NotebookLM)

Free knowledge repository. Upload as many as 50 sources into each notebook. Get a chatbot that answers from sources, narrated slides, podcast-style audio, quizzes, …

  • Chatbot example: Options textbook
  • Narrated slides example: Kapadia-Ostdiek-Weston paper
  • Podcast example: Put-call parity from textbook

Chatbot is great. Videos are good for a short change of pace. We can specify only use this part of the source for video or podcast. Cannot revise directly but can regenerate with new instructions.

RAG Chatbots

Retrieval Augmented Generation

1

Prepare

Split your documents into chunks, turn each into a numeric “embedding,” and store them in a database

2

Retrieve

For a question, find the chunks most similar to it and hand them to the model

3

Answer

The model responds grounded in those chunks — and can cite which document each came from

Gemini Notebook uses RAG

Build Your Own

Chunk, embed, match

  • Claude can embed your sources into a database
  • Finding chunks that best match a prompt is a mechanical exercise that can be scripted

Read and interpret

  • Reading the chunks and responding is AI. Could create a custom chatbot that makes API calls (more later).
  • Or could use Claude as the AI. Create a Claude skill and include the database

Why Build Your Own

  • More than 50 sources (research database — more later)
  • More control over answers (via system prompt — more later)
