What Happens When You Chat

It Predicts the Next Word

The whole trick

  • A large language model takes text and produces a probability distribution over what comes next
  • It samples one token, appends it, and repeats
  • That is all it does — one token at a time

Why that becomes intelligence

  • Trained on trillions of words
  • To predict the next word in a financial analysis, it has to learn finance
  • Competence is a side effect of getting very good at prediction

When Claude writes a paragraph, at every step it is asking: “given everything so far, what should come next?”

Tokens

Not words — pieces of words

  • The model reads and writes in tokens: sub-word chunks, ~100,000 of them
  • "chatbot" → ["chat", "bot"]
  • "unhelpful" → ["un", "help", "ful"]

Why you should care

  • Everything is metered in tokens — what you pay, and what fits
  • The context window is a token budget: Claude’s is ~200,000 tokens, roughly 500 pages
  • Fill it up and the earliest text falls out of view

“Context window” and “how much can it remember in one conversation” are the same question — measured in tokens.

Parameters

The knobs learned in training

  • A model’s parameters are the billions of numbers adjusted during training
  • Training = show it text, have it predict the next token, nudge the numbers when it is wrong, repeat trillions of times
  • The finished parameters are the model

Knowledge, then values

  • Pre-training gives the model its knowledge
  • A second stage — fine-tuning and human feedback (RLHF) — gives it its behavior: helpful, honest, safe
  • Anthropic calls its approach Constitutional AI

More parameters and more training data have meant more capability — GPT-2 had 1.5 billion parameters; today’s frontier models are a thousand times larger.

Why the Same Prompt Gives Different Answers

Sampling

  • The model gives a distribution; it then samples from it
  • Temperature controls the gamble: near 0 it always takes the likeliest token; higher, it takes chances
  • Low temperature → predictable and safe; high → varied and creative

Why hallucinations happen

  • The model is trained to produce plausible next tokens, not true ones
  • Fluency is not truth — a confident, well-formed answer can be wrong
  • This is why we verify, and why later sessions are full of checking

Same reason a vague prompt gives a vague answer: you leave the distribution wide. A specific prompt collapses it to a narrow, useful range.

The Layers You Control

System Prompts

The standing instructions

  • Before your message, the model gets a system prompt: who it is, how to behave, what it may and may not do
  • You never see it in a chatbot — the app writes it
  • When you build your own tools, you write it

Why it is powerful

  • “You are a patient tutor; give hints, never the final answer”
  • “You are a vendor rep with a hidden price floor; stay in character”
  • The same model becomes a tutor, a negotiation partner, or a data analyst — by its system prompt alone

Much of what we build later in the course is really just a carefully written system prompt wrapped around the same Claude.

Tools

A model that can act

  • On its own, a model only produces text
  • Give it tools — run code, search the web, query a database, read a file — and it can do things
  • The model decides when to reach for a tool and reads back the result

This is the leap

  • Text-only: it can tell you how to compute the answer
  • With a code tool: it computes the answer and shows you the chart
  • Tomorrow’s session is entirely about what tools unlock

A chatbot with tools is the difference between advice and work. Most of this course lives on the tool side.

Memory

The model has none of its own

  • Each request is fresh; the model remembers nothing between them
  • A conversation “remembers” only because the app resends the whole history each turn
  • Run out of context window and the early turns drop away

Giving it real memory

  • A memory file the model reads at the start and updates as it goes
  • A database it can search — notes, past chats, your documents
  • We will build both; “memory” is just information you arrange to hand back

This matters for privacy too: what the model “knows” about you is whatever you or the app chooses to resend — nothing more.

Reasoning

Thinking before answering

  • Newer models can produce a private chain of reasoning before the final reply
  • More tokens spent thinking → better answers on hard, multi-step problems
  • You can often turn “extended thinking” up or down

When it is worth it

  • Worth it: proofs, multi-step analysis, tricky code, careful critique
  • Overkill: “reformat this table” or “summarize this paragraph”
  • More reasoning costs more tokens and time — match it to the stakes

This is why a model can seem to “show its work” now. The scratchpad is real — it just usually stays hidden.

The Anatomy, In One Slide

A model predicts the next token using its trained parameters. Around it you place a system prompt that sets its role, tools that let it act, memory that lets it carry context, and reasoning that lets it think first. Everything we build this course is some arrangement of those six pieces.
